* 1️⃣ WASM 的灵魂:栈(Stack)
大部分语言 =先算括号、再算乘除=,那是"顺序执行"的心智模型。

WASM 不一样,它是 *栈机*:
#+begin_quote
指令从栈顶弹数据,把结果压回栈顶。没有"变量",数据都在栈上。
#+end_quote

用 RPN(逆波兰式)想最舒服:
- =1 + 2= 写成 =1 2 +=
- =(1 + 2) * 3= 写成 =1 2 + 3 *=

举个实际例子:计算 =1 + 2= 的 WAT:
#+begin_src wat
(module
  (func (export "add") (result i32)
    i32.const 1
    i32.const 2
    i32.add))
#+end_src

执行过程(想象一个竖着的栈):
| 指令          | 栈内容        |
|---------------+---------------|
| =(start)=     | =[]=          |
| =i32.const 1= | =[1]=         |
| =i32.const 2= | =[1, 2]=      |
| =i32.add=     | =[3]=         |

=i32.add= 把栈顶两个数弹出来相加,再把结果 =3= 压回去。函数结束时栈顶的 =3= 就是返回值。

* 2️⃣ 数值类型
WASM 有四种数值类型(常用两种):

| 类型  | 位宽  | 说明                    | 常量写法示例       |
|-------+-------+-------------------------+--------------------|
| =i32= | 32 位 | 整数(最常用)           | =i32.const 5=      |
| =i64= | 64 位 | 更大的整数              | =i64.const 100=    |
| =f32= | 32 位 | 单精度浮点              | =f32.const 1.5=    |
| =f64= | 64 位 | 双精度浮点              | =f64.const 3.14=   |

注意区分:浮点数常量是 =f32.const / f64.const=,整数是 =i32.const / i64.const=,别混。

*i32* 整数里还能写负数、十六进制、十六进制带下划线:
#+begin_src wat
  i32.const -5        ;; 负数
  i32.const 0x2a      ;; 十六进制 = 42
  i32.const 0xFF      ;; = 255
  i32.const 1_000_000 ;; 下划线分隔,纯可读性
#+end_src

* 3️⃣ 算术指令:一图看懂
整数(=i32=/=i64=)算术指令直接 =类型.操作=:

| 指令          | 作用              | 例(栈)              |
|---------------+-------------------+---------------------|
| =i32.add=     | 加                | =5 3 -> 8=          |
| =i32.sub=     | 减(栈顶减栈顶下) | =5 3 -> 2=          |
| =i32.mul=     | 乘                | =5 3 -> 15=         |
| =i32.div_s=   | 除法(有符号)     | =7 2 -> 3=          |
| =i32.div_u=   | 除法(无符号)     | =7 2 -> 3=          |
| =i32.rem_s=   | 取余(有符号)     | =7 2 -> 1=          |
| =i32.rem_u=   | 取余(无符号)     | =7 2 -> 1=          |

浮点(=f32=/=f64=)几乎一样,但:
- 除法没有 =_s/=_u= 之分:直接 =f32.div=
- 多了些特殊: =f32.sqrt= 开方, =f32.floor= 向下取整, =f32.ceil= 向上取整, =f32.abs= 绝对值

* 4️⃣ 完整示例:计算 (1 + 2) * 3
文件 =arith.wat=:
#+begin_src wat
(module
  (func (export "calc") (result i32)
    i32.const 1
    i32.const 2
    i32.add       ;; 栈: [3]
    i32.const 3
    i32.mul))     ;; 栈: [9]
#+end_src

编译运行:
#+begin_src bash
  wat2wasm arith.wat -o arith.wasm
  wasmtime run --invoke calc arith.wasm
#+end_src

输出 =9=。确认你理解了"先算 1+2 得到 3,再乘 3"。

* 5️⃣ 减法容易犯的坑
栈是 LIFO(后进先出):
- =7 3 i32.sub= 是 =7 - 3 = 4=
- 别写成 =3 - 7=,那得 =3 7 i32.sub=

* ✍️ 本课练习(必须写)

** 练习 2(除法)
