# Project language convention

Use English throughout all project code, including identifiers, comments,
diagnostic messages, sample data, example content, and developer documentation.
Do not introduce Chinese text in these materials. This applies to existing code
and examples as well as new additions, throughout the project, not just `lib/`.

Code and comments under `entries/` follow the same rule. Existing user-authored
diary and novel prose is document content; preserve its original language unless
the user requests a translation. The library must continue to support Unicode
content at runtime.
